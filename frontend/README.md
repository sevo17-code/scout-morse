# Scout Morse - الفرونت إند

React + Vite + Tailwind، بيتكلم مع الباك إند اللي عملناه قبل كده.

## 1. التثبيت

```bash
cd frontend
npm install
```

## 2. إعداد متغيرات البيئة

```bash
cp .env.example .env
```

سيب `VITE_API_URL` زي ما هي وانت بتشتغل محلي (`http://localhost:5000/api`)، وغيّرها لرابط الباك إند بتاعك لما تنشره أونلاين.

## 3. حط لوجو المجموعة

حط صورة اللوجو في `public/logo.png` (نفس الاسم بالظبط، عشان الهيدر بيقرأها من `/logo.png`).

## 4. تشغيل المشروع

شغّل الباك إند الأول (من فولدر `backend`: `npm run dev`)، وبعدين من هنا:

```bash
npm run dev
```

هيفتحلك على `http://localhost:5173`

## الصفحات المتاحة

| الصفحة              | الرابط          | ملاحظات                          |
| -------------------- | ---------------- | --------------------------------- |
| الرئيسية              | `/`               | -                                  |
| تسجيل الدخول           | `/login`          | -                                  |
| حساب جديد              | `/register`       | فيه حقل اختياري لكود الأدمن       |
| تدرب                   | `/exercises`      | تدريب حر، مش محتاج تسجيل دخول     |
| الامتحان                | `/exam`           | محتاج تسجيل دخول                  |
| لوحة الصدارة            | `/leaderboard`    | مفتوحة للجميع                     |
| لوحة الأدمن             | `/admin`          | أدمن بس (انت والكابتن)            |

## النشر المجاني

- **Vercel** أو **Netlify** — اربط الريبو، وحط `VITE_API_URL` في إعدادات Environment Variables بتاعة المشروع على رابط الباك إند المنشور.
- متنساش تحدّث `FRONTEND_URL` في إعدادات الباك إند (`.env`) على رابط الفرونت إند المنشور عشان الـ CORS يشتغل صح.
